# rerune-packages

This repository serves the signed APT and RPM repositories for the [rerune CLI](https://rerune.io) at <https://pkg.rerune.io>.

The `gh-pages` branch is generated by the rerune release workflow on every tagged release and is force-pushed as a single commit. Do not edit it by hand.

Other install channels: `brew install basalbit/tap/rerune` (macOS and Linux) and `yay -S rerune-bin` (Arch Linux, Omarchy).
