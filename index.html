rerune packages

Signed package repositories for the rerune CLI.

Debian, Ubuntu, Linux Mint, Pop!_OS (APT)

Add the repository and install rerune for amd64 or arm64:

curl -fsSL https://pkg.rerune.io/rerune-archive-keyring.gpg | sudo tee /usr/share/keyrings/rerune-archive-keyring.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/rerune.sources >/dev/null <<'EOF'
Types: deb
URIs: https://pkg.rerune.io/apt
Suites: stable
Components: main
Architectures: amd64 arm64
Signed-By: /usr/share/keyrings/rerune-archive-keyring.gpg
EOF
sudo apt update && sudo apt install rerune rerune-archive-keyring

Upgrade with sudo apt update && sudo apt install --only-upgrade rerune or a normal sudo apt upgrade. The rerune-archive-keyring package keeps the signing key in /usr/share/keyrings/rerune-archive-keyring.gpg up to date. Key fingerprint: 25A4 3D9B C619 2114 6E1D 6FCE 9CE4 DBD0 53BF 88CB (rerune.asc).

Fedora, RHEL, Rocky Linux, AlmaLinux, CentOS Stream (RPM)

Import the signing key, add the repository and install rerune for x86_64 or aarch64 with dnf:

sudo rpm --import https://pkg.rerune.io/rerune.asc
sudo curl -fsSLo /etc/yum.repos.d/rerune.repo https://pkg.rerune.io/rpm/rerune.repo
sudo dnf install rerune

The repository signs its packages and its metadata (gpgcheck=1, repo_gpgcheck=1). dnf may ask once more to import the same key for the repository metadata; accept it when the fingerprint is 25A4 3D9B C619 2114 6E1D 6FCE 9CE4 DBD0 53BF 88CB. Upgrade with sudo dnf upgrade --refresh rerune, or sudo yum upgrade rerune on systems without dnf.

openSUSE Leap and Tumbleweed (zypper)

The same RPM repository works with zypper (best-effort; tested on openSUSE Leap 15.6 and Tumbleweed):

sudo rpm --import https://pkg.rerune.io/rerune.asc
sudo zypper addrepo https://pkg.rerune.io/rpm/rerune.repo
sudo zypper refresh && sudo zypper install rerune

Upgrade with sudo zypper refresh && sudo zypper update rerune.

Arch Linux, Manjaro, EndeavourOS, Omarchy (AUR)

Install rerune-bin from the AUR with yay -S rerune-bin (or paru).

NixOS, nix-darwin, Home Manager and Nix (flake)

Try rerune with nix run github:BasalBit/nix-rerune -- version, install it with nix profile install github:BasalBit/nix-rerune and upgrade with nix profile upgrade --all. In a NixOS, nix-darwin or Home Manager flake, add the input rerune.url = "github:BasalBit/nix-rerune";, use inputs.rerune.packages.${pkgs.stdenv.hostPlatform.system}.default, and upgrade with nix flake update rerune, then rebuild. See BasalBit/nix-rerune.

macOS and other Linux systems (Homebrew)

Install with brew install BasalBit/tap/rerune and upgrade with brew upgrade BasalBit/tap/rerune.

Every install can also update with rerune update.
